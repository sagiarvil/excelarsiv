## BÖLÜM II: 14KB FIRST-PACKET AST BÜTÇESİ, COLBERT LATE-INTERACTION & HUMANIZER PROTOKOLÜ
### 2.1. 14.336 Bayt (14KB) TCP/TLS AST Kuralı
TCP bağlantılarında yavaş başlangıç (TCP Slow Start / initcwnd) mekanizması gereği ilk veri gidiş-gelişinde (Initial Round Trip Time - RTT) aktarılan veri tavanı yaklaşık 14.336 bayttır.
1. Sayfanın birincil anlamsal varlığı (Primary Entity),
2. Sayfanın tekil `<h1>` başlığı,
3. AEO Yanıt Bloğu (`div.hero-answer-engine.mobile-thumb-safe`),
4. Schema.org `@graph` JSON-LD bloğunun tamamı (WebSite, WebPage, BreadcrumbList, Organization) ilk 14.336 bayt içinde sonlanmak zorundadır. Bu sayede GPTBot, PerplexityBot ve Google Alexandria stream kesilmeden, ek soket beklemeden varlığı doğrudan hafızaya alır.

### 2.2. ColBERT Late-Interaction (MaxSim) Matrisi & Humanizer Doğal Dil Standardı
Klasik BM25 ve kaba kosinüs benzerliği artık yetersizdir. Modern arama yapay zekaları her sorgu token'ı ile içerik token'ı arasındaki maksimum benzerliklerin toplamını (MaxSim) hesaplar:

$$Score(Q, D) = \sum_{i \in Q} \max_{j \in D} \left( E(q_i) \cdot E(d_j)^\top \right)$$

Metinler bu formüle uyum sağlamak için:
- **Humanizer Filtresi (Wikipedia 26 Tells):** Metinler "not only X but Y", one-line closer ("bunu bir düşünün"), "delve", gereksiz tireler (—) ve sahte derinlik kalıplarından arındırılır.
- **Yüksek Bilgi Entropisi:** Dolgu sıfat ve zamirlerden arındırılmış, doğrudan gerçek veri sunan insan uzmanlığı dili kullanılır.
- Her paragraf doğrulanabilir RDF Üçlüsü ([Özne] - [Yüklem] - [Nesne]) formatında kurgulanır.
- Alıntı çapa blokları `data-ai-citation-anchor="true"` özniteliğiyle işaretlenir.

    'https://yandex.com/indexnow'
  ],
  webSubHubs: [
    'https://pubsubhubbub.appspot.com/',
    'https://pubsubhubbub.superfeedr.com/'
  ],
  feeds: [
    'https://example.com/feed.xml',
    'https://example.com/mobile/feed.xml'
  ]
};
async function executeTriplePush(urls) {
  console.log(`🚀 [Triple-Push] ${urls.length} adet URL anlık dağıtıma iletiliyor...`);
  // 1. IndexNow Multi-Hub
  const payload = JSON.stringify({
    host: CONFIG.host,
    key: CONFIG.indexNowKey,
    keyLocation: `https://${CONFIG.host}/${CONFIG.indexNowKey}.txt`,
    urlList: urls
  });
  CONFIG.indexNowEndpoints.forEach(endpoint => {
    const u = new URL(endpoint);
    const req = https.request({
      hostname: u.hostname, path: u.pathname, method: 'POST',
      headers: { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(payload) }
    }, res => console.log(`  ✅ [IndexNow: ${u.hostname}] HTTP ${res.statusCode}`));
    req.on('error', err => console.error(`  ❌ [IndexNow: ${u.hostname}] Hata:`, err.message));
    req.write(payload);
    req.end();
  });
  // 2. WebSub Hubs Ping
  const params = CONFIG.feeds.map(f => `hub.url=${encodeURIComponent(f)}`).join('&') + '&hub.mode=publish';
  CONFIG.webSubHubs.forEach(hub => {
    const u = new URL(hub);
    const req = https.request({
      hostname: u.hostname, path: u.pathname, method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded', 'Content-Length': Buffer.byteLength(params) }
    }, res => console.log(`  ✅ [WebSub: ${u.hostname}] HTTP ${res.statusCode}`));
    req.on('error', err => console.error(`  ❌ [WebSub: ${u.hostname}] Hata:`, err.message));
    req.write(params);
    req.end();
  });
}
module.exports = { executeTriplePush };

## BÖLÜM VII: GOOGLE SERP GÖRÜNÜMÜ, MARKA KİMLİĞİ VE CTR HÂKİMİYETİ ($10M TIER SERP DOMINANCE)

### 7.1. Googlebot-Image 48px Katsayılı Favicon Standartı (Mavi Dünya İkonu İmha Protokolü)

2. **Kare Multi-Res ICO:** Kök dizindeki `favicon.ico`, bünyesinde en az 16x16, 32x32 ve 48x48 kare katmanlarını barındırmalıdır.
3. **HTML <head> Zorunlu İkon Bloğu:** İstisnasız tüm HTML sayfalarının `<head>` bloğunda aşağıdaki deklarasyon eksiksiz yer almalıdır:

### 7.2. Google Site Names (Kurumsal Marka Adı vs Ham Domain Senkronizasyonu)

4. **Organization Logo Eşleşmesi:** `Organization` şemasındaki logo URL'i (`/android-chrome-512x512.png` veya `/assets/images/logo.png`) doğrudan erişilebilir ve kare formatta olmalıdır.

      },

      }
