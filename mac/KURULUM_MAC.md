# 🍎 Antigravity macOS Kurulum & Araç Kılavuzu (Apple Silicon & Intel)

Bu eklenti paketi **macOS** işletim sisteminin mimarisine uygun olarak `.exe` bağımlılıklarından arındırılmış, yerel Mac araçlarıyla yapılandırılmıştır.

---

## ⚡ Hızlı Kurulum

Terminal uygulamasını açın ve klasör içinde çalıştırın:

```bash
chmod +x install_mac.sh && ./install_mac.sh
```

---

## 🛠️ macOS Geliştirici Ekosistemi & Tavsiye Edilen Programlar

macOS üzerinde en stabil ve hızlı yazılım geliştirme deneyimi için şu resmi ve modern Mac araçları tavsiye edilir:

### 1. Paket Yöneticisi: Homebrew (macOS Standartı)
Tüm derleyicileri ve binary araçları tek satırda kurun:
```bash
brew install node python git php composer mkcert
```

### 2. Hepsi Bir Arada Web Geliştirme: Laravel Herd (Önerilen)
* **İndirme:** [Laravel Herd macOS](https://herd.laravel.com)
* **Özellikler:** PHP 8.3/8.4, Nginx ve DNS `.test` alan adlarını tek tıkla kurar. Sıfır konfigürasyonla çalışır.

### 3. macOS Veritabanı Yöneticisi: DBngin
* **İndirme:** [DBngin (dbngin.com)](https://dbngin.com)
* **Özellikler:** MySQL 8.4, PostgreSQL ve Redis sunucularını tek tıkla başlatıp durduran modern macOS uygulaması.

### 4. Alternatif Klasik Stack: MAMP PRO / MAMP
* **İndirme:** [MAMP & MAMP PRO](https://www.mamp.info)
* Apache, Nginx, MySQL ve PHP sürümlerini içeren klasik Mac aracı.
