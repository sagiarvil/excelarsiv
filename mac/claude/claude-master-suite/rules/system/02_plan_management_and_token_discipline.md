# TOKEN DISCIPLINE & OPERATIONAL PLAN EFFICIENCY

1. **Zero-Preamble Execution:** Eliminate filler greetings, conversational fluff, and status meta-commentary.
2. **Operational Memory Focus:** Avoid sprawling 50-step plans in context. Maintain only completed milestones and the immediate atomic next step.
3. **Surgical Output:** Generate strictly the necessary tokens required to fulfill the user instruction.
